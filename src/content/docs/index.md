Welcome to the public documentation for the
[`@jsonanalytix/*`](https://github.com/jsonanalytix) monorepo.

This site is intentionally minimal at the moment — the information
architecture, package reference pages, playbooks, and operations content
are tracked in plan **P21** and land in follow-up tasks (T1–T7).

## What lives here

- **Packages** — overview, install, and usage examples for every public
  `@jsonanalytix/*` package, plus auto-generated TypeDoc reference pages.
- **Playbooks** — operational guides lifted from the Atlas monorepo
  (`docs/operations/`, `docs/runbooks/`).
- **Prompt Library** — versioned system prompts that ship in
  [`@jsonanalytix/prompts`](https://github.com/jsonanalytix).
- **Observability** — PostHog/Sentry/logger conventions and dashboards.
- **Operations** — deployment, environment variables, RLS audit, AI
  budget, e2e and performance.

## Boundary

No client-specific copy, credentials, `NEXT_PUBLIC_*` values, or service
role keys live in this repository. See the
[README](https://github.com/jsonanalytix/docs#readme) for details.
