# `@jsonanalytix/docs`

Public documentation site for the [`@jsonanalytix/*`](https://github.com/jsonanalytix) monorepo.
Built with [Astro Starlight](https://starlight.astro.build/) and deployed to
[Cloudflare Pages](https://pages.cloudflare.com/) at
[`https://docs.theintelligenceagency.com`](https://docs.theintelligenceagency.com).

This repository implements **P21 — Public docs site** from the
`AtlasIntelligence` project plan
(`docs/project-streamlining-recommendations.md`, §7.4).

## Repository boundary

- **No client-specific copy.** This site documents the public
  `@jsonanalytix/*` packages, runbooks, and operational playbooks only.
- **No credentials.** No `.env`, no `NEXT_PUBLIC_*` values, no
  `SUPABASE_SERVICE_ROLE_KEY`, no Anthropic keys, no Supabase project IDs.
  CI enforces this with a secrets-leak `rg` guard (added in T6).
- **No coupling to `tia-intelligence-starter` (P14).** The
  `starter-template/` IA slot stays a stub until P14 ships.

## Local development

Requires Node 20 (see [`.nvmrc`](.nvmrc)) and pnpm 10.

```bash
nvm use
pnpm install
pnpm dev
```

The dev server is available at [`http://localhost:4321`](http://localhost:4321).

## Build

```bash
pnpm build
pnpm preview
```

Output is written to `dist/`.

## Deploy

Cloudflare Pages project `jsonanalytix-docs`, configured in T5/T6:

- Build command: `pnpm build`
- Output directory: `dist`
- DNS: `CNAME docs -> jsonanalytix-docs.pages.dev` on
  `theintelligenceagency.com`.

> **Why Pages and not Workers?** The Atlas monorepo's deployment rule
> (`.cursor/rules/deployment.mdc`) covers the Workers-hosted apps
> (`til-web`, `til-admin`, `til-storybook`). This is a separate
> documentation-only repo with no `[assets]` binding requirements, so
> Cloudflare Pages is the simpler, supported path. The exception is
> intentional and documented here.

## TypeDoc reference pages

Per-package API reference pages under `src/content/docs/packages/<pkg>/reference/`
are generated by a TypeDoc job that lives in the `AtlasIntelligence` repo.
On tag, that job opens a PR against this repo with the regenerated markdown.
See P21 / T2.

## Storybook embed

The `/ui/` page embeds the Storybook deployed by the Atlas monorepo at
[`https://til-storybook.jason-3f4.workers.dev`](https://til-storybook.jason-3f4.workers.dev).
This site never bundles Storybook itself.
